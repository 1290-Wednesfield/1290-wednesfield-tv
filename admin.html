Duty NCO's

Enter the duty SNCO and duty JNCO for each parade night.

Automatic Duty Rota

Upload one Excel or CSV list containing your SNCO's and JNCO's. The system will use the list in order, keep the same SNCO for Monday and Wednesday in the same week, and move to the next JNCO every parade night.

No staff list loaded.
File format: use columns Role and Name.
Example: SNCO | SGT Smith and JNCO | Cpl Jones.

Inter-Flight

Manage the four flight names, points and display order. Changes appear on the TV automatically.

Flight Standings

Set the flight names and current points below. Use the arrows to change the display order. The TV will always show the highest-scoring flight first.

Uniform Manager

Create your uniform library, upload the approved poster/image for each dress code, and assign the correct uniform to each parade night and cadet group.

Uniform Library

Add or edit dress codes here. Upload the actual image/poster you want the TV system to use. Nothing is automatically published from an uploaded image until you save it.

Recommended format: 4:3, matching the squadron uniform-guide posters.
